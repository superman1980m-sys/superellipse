## Описание проекта

Программа визуализирует суперэллипс (кривую Ламе) и позволяет интерактивно менять показатель `n` с помощью ползунка. При `n = 2` получается обычный эллипс; при других значениях форма постепенно меняется от ромбовидной до почти прямоугольной.

Проект выполнен на Python с использованием объектно-ориентированного подхода и встроенной библиотеки Tkinter. Он соответствует заданию «Суперэллипс» из лабораторной работы «Простая анимация»: полуоси изначально равны, а параметр `n` регулируется слайдером. Также используется обобщённая параметризация суперэллипса.

## Функциональные возможности

### Основной функционал
- Отрисовка суперэллипса с равными полуосями.
- Интерактивное изменение параметра `n` в диапазоне от 0.5 до 8.
- Обновление рисунка при перемещении ползунка.
- Координатная сетка и оси для наглядности.
- Кнопка сброса к `n = 2`.

### Математическая модель

Обобщённый суперэллипс задаётся параметрически:

`x(t) = a · sign(cos(t)) · |cos(t)|^(2/n)`

`y(t) = b · sign(sin(t)) · |sin(t)|^(2/n)`

где `t` изменяется от `0` до `2π`, `a` и `b` — полуоси. В этой реализации `a = b`, чтобы выполнить начальное условие задания.

## Управление

- **Ползунок** — изменяет показатель `n`.
- **Сбросить n = 2** — возвращает обычный эллипс.
- **Стрелки влево/вправо** — предусмотрены как клавиши управления параметром; для удобства можно пользоваться ползунком.

## Пример использования

1. Запустите `python main.py`.
2. Передвиньте ползунок `n`.
3. Сравните форму при `n = 1`, `n = 2` и `n = 6`.
4. Нажмите «Сбросить n = 2», чтобы вернуться к обычному эллипсу.
